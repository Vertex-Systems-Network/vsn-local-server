# Source closure semantics — 0.21

A phase marked 100% in the 0.21 roadmap means its **defined source/product contract is implemented and the offline integration gate has no known source-scope gap**. It does not mean every external operating-system runner or production environment has certified it. Native/production certification evidence belongs to P30.

This distinction prevents two opposite errors: keeping finished source phases permanently yellow because a macOS runner is unavailable, or declaring Stable 1.0 because source code exists without external evidence.
