# Source Control

## Git
Status, diff, stage/unstage, discard, commit, branches (switch/create), fetch, pull, push, init and clone. Credentials come from Git Credential Manager or your SSH keys — VSN never asks for or stores them.

## SVN
For Subversion working copies: checkout, status, update, add, revert, commit, history and per-file diff. Uses the `svn` command line and its saved credentials.

Changes are blocked while a space is locked.
