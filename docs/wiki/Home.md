# VSN Devify

VSN Devify is a local development platform for Windows, macOS and Linux: a desktop app plus a background **VSN Agent** that runs your projects, services and tools on this computer — like Laragon, Herd or Local, with spaces, databases, mail, API client, source control, sharing, backups and an AI assistant built in.
